# Время сервера

Время важно для LiveQX: от него зависят окна [расписания](SCHEDULE_USER.md) и метки времени в журнале воспроизведения и журнале действий.

Раздел **Настройки → Время** (страница «Системное время»). Менять настройки может **только администратор**.

## Что такое «эффективное время»

LiveQX использует собственное «эффективное» время: это системные часы сервера плюс поправка, заданная выбранным источником. **LiveQX не меняет системные часы самой операционной системы.** Поправка применяется только внутри LiveQX: к расписанию, журналу воспроизведения и журналу действий.

Блок **Текущее состояние** показывает активный источник, текущую поправку, эффективное время и показания системных часов.

## Источник времени

Выбирается один из трёх режимов:

- **Локальное время сервера** — используются часы хоста как есть, без поправки. Режим по умолчанию.
- **NTP** — LiveQX опрашивает один или несколько SNTP-серверов и учитывает найденное расхождение как поправку к системным часам.
- **Вручную** — фиксированное время, заданное оператором. LiveQX запоминает разницу между заданным временем и часами хоста, и она сохраняется после перезапусков.

Если сервер сам синхронизируется с NTP средствами операционной системы (chrony, systemd-timesyncd), оставьте режим «Локальное время сервера».

## Часовой пояс сервера

Задаётся **названием IANA** (например, `Europe/Moscow`, `Asia/Yekaterinburg`, `UTC`). Выберите из списка **Пресет** или введите своё значение (пункт «— своё значение —»).

Часовой пояс сервера:

- используется для отображения времени;
- наследуется каналами, у которых не задан свой пояс: по нему считаются окна расписания.

Часовой пояс — настройка представления, он не зависит от выбранного источника времени.

## Настройки NTP

Блок появляется при выборе режима NTP:

- **Включить опрос NTP**;
- **NTP-серверы** — по одному в строке, в формате `host` или `host:port`;
- **Интервал опроса** — в секундах;
- **Последняя синхронизация** и **Последнее смещение** — результат последнего опроса;
- **Проверить серверы** — разовый опрос с таблицей: сервер, статус, смещение, время отклика (RTT).

## Ручное время

В режиме «Вручную» введите время, которое LiveQX должен считать текущим. Время трактуется в часовом поясе вашего браузера; кнопка **Время из браузера** подставляет текущее время вашего компьютера. На сервер сохраняется только разница с часами хоста.

## Часовой пояс канала

У каждого канала может быть **свой** часовой пояс: страница канала → вкладка **Конфигурация** → **Часовой пояс**. По умолчанию канал **наследует** пояс сервера. Задать свой имеет смысл, если канал вещает для другого региона: тогда окна его расписания считаются по местному времени.

Новый пояс канала применяется **при следующем запуске канала**. Если канал наследует пояс сервера, то при смене пояса сервера он подхватывает новое значение автоматически.

## Часовой пояс и расписание

Иерархия: **сервер → канал**. Время начала и конца ежедневных, недельных и месячных записей расписания считается в поясе канала. Записи «один раз» всегда задаются в UTC. Отдельного пояса у записи расписания нет.

## Если расписание срабатывает не вовремя

1. Сравните эффективное время в блоке «Текущее состояние» с реальным.
2. Проверьте часовой пояс сервера.
3. Проверьте часовой пояс канала: наследуется ли он, а если задан вручную — верно ли он указан.
4. Для записей «один раз» убедитесь, что время указано в UTC.
5. Если нужно — исправьте источник времени (NTP или ручная поправка).

## Влияние на работающие каналы

Смена часового пояса или источника времени не останавливает каналы. Меняется только то, как считаются следующие срабатывания расписания и метки времени.
