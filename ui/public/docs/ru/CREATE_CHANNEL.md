# Создание канала

Канал — это один эфир: плейлист, превращаемый в непрерывный видеопоток и отправляемый на выходы. В этой статье — как создать канал и что означают поля формы.

**Кто может создавать каналы:** только администратор. Кнопка **Создать канал** другим ролям не показывается.

## Где создаётся

Левое меню → **Каналы** → **Создать канал**. Форма состоит из двух шагов.

## Шаг 1. Базовые параметры

### Имя

Латиница, цифры, `_` и `-`, до 64 символов. Имя уникально. **Изменить его после создания нельзя.**

### Разрешение и частота кадров

- **Разрешение** — в формате `ширина×высота`, например `1920x1080` (по умолчанию).
- **Целевой FPS** — от 1 до 120, по умолчанию 25.

Разрешение и FPS **нельзя изменить** после создания канала. Если они нужны другие — создайте новый канал.

### Видео

- **Видео-кодек** — H.264 (по умолчанию) или MPEG-2 Video. MPEG-2 нужен только для старых приставок, которые не декодируют H.264; он всегда кодируется на процессоре.
- **Энкодер** — `auto` (по умолчанию), `cpu`, `nvenc`, `qsv`, `vaapi`. Аппаратные варианты доступны, если на сервере есть подходящая видеокарта и сборка с её поддержкой. В режиме `auto` сервер выбирает сам.
- **Битрейт** — в кбит/с, от 100 до 100 000, по умолчанию 4000.
- **Управление битрейтом:**
  - **CBR** — постоянный битрейт. Обязателен для MPEG-TS multicast (приставки и гостиничные декодеры рассчитывают на фиксированный поток).
  - **VBR** — переменный с потолком; подходит для HLS и RTMP. Можно задать максимальный битрейт (0 — выбирается автоматически).
  - **CRF** — по качеству, только для программного кодирования x264. На аппаратных энкодерах и MPEG-2 молча заменяется на VBR (в лог пишется предупреждение).
- **Пресет** (только H.264) — от `ultrafast` до `veryslow`, по умолчанию `veryfast`. Быстрее — меньше нагрузка на процессор, медленнее — лучше сжатие.
- **Макс. B-кадров**, **Длина GOP**, **Профиль и уровень H.264 / MPEG-2** — тонкие настройки для строгих приёмников. Значения по умолчанию подходят в большинстве случаев; подробные подсказки показаны у каждого поля.

### Аудио

- **Аудио-кодек** — AAC-LC (по умолчанию) или MP2 (классический DVB-кодек для приставок).
- **Битрейт аудио** — 32–512 кбит/с, по умолчанию 128.
- **Частота дискретизации** — 44100 или 48000 Гц (по умолчанию).

### NUMA-узел

Номер NUMA-узла сервера (0–7), на котором работает канал. На серверах с одним процессором оставьте 0.

### Длительность фото по умолчанию

Сколько секунд показывать фотографию, у которой не задана своя длительность. По умолчанию 10 секунд.

### Источник контента

- **выкл** — канал не читает файлы из папки; плейлист заполняется вручную или канал играет только live-источники.
- **Passthrough** — файлы читаются прямо из указанной папки.
- **Кэш** — фоновая служба копирует файлы из папки (например, сетевой шары) в локальный кэш, а канал играет из кэша.

Подробнее: [Источник контента](CONTENT_SOURCE_USER.md).

### Заглушка

Статичная картинка, которая показывается, когда в плейлисте нечего играть. Путь указывается на сервере.

### Журнал воспроизведения

Что и когда играло:

- **Выкл** — ничего не записывается.
- **Файл** — JSONL-файлы по дням в каталоге канала.
- **SQLite** — общая база для всех каналов с быстрым поиском; записи старше заданного числа дней (по умолчанию 90) удаляются автоматически.

## Шаг 2. Назначения выходов

При создании настраивается **первый выход**:

- **Тип выхода** — SRT, Multicast, RTMP или HLS.
- **ID выхода** — произвольный идентификатор (по умолчанию `main`).
- Поля зависят от типа: адрес и порт, URL или каталог. Для SRT и Multicast можно выбрать сетевой интерфейс отправки; для Multicast — TTL.
- Для Multicast открывается блок **MPEG-TS / IPTV**: имя сервиса, провайдер, Service ID, TSID, ONID, скорость мультиплекса и периоды SDT/PAT. Если несколько каналов вещают в одну multicast-подсеть, у них **должны быть разные Service ID**, иначе приёмник склеит их в одну программу.

Дополнительные выходы добавляются позже на вкладке **Выходы**. Подробнее: [Добавление выхода](ADD_OUTPUT.md).

## После создания

Канал появится в списке остановленным и откроется его страница. Дальше:

1. Добавьте контент — [Плейлист канала](PLAYLIST_USER.md).
2. Нажмите **Запустить**.

Вкладки страницы канала: **Обзор**, **Плейлист**, **Расписание**, **Выходы**, **Лог**, **Конфигурация**, **Наблюдатель**, **Доступы** (последняя — для администратора).

## Изменение настроек позже

Вкладка **Конфигурация** позволяет изменить большинство параметров, в том числе кодирование, переход по умолчанию, заглушку, источник контента, журнал воспроизведения и часовой пояс канала. Часть изменений применяется только после перезапуска канала — на странице об этом предупреждают. Не меняются имя, разрешение и FPS.

## Удаление канала

Меню «⋯» на странице канала → **Удалить канал** (только администратор). Для подтверждения нужно ввести имя канала.

Удаление останавливает все выходы и стирает конфигурацию канала и его кэш. Логи остаются на диске. Исходные файлы на сервере и шарах **не затрагиваются**.
