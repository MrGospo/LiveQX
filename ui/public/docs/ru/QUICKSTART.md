# Быстрый старт

Этот документ проведёт вас от входа в систему до работающего канала с одним выходом.

## 1. Вход в систему

Откройте адрес LiveQX в браузере (по умолчанию порт `8080`). На экране входа введите имя пользователя и пароль.

**Первый вход после установки.** Установщик создаёт администратора `admin` и сохраняет его одноразовый пароль в файл `/var/lib/liveqx/state/initial_admin_password.txt` на сервере. Войдите с этим паролем — система сразу попросит задать новый (не короче 12 символов). После смены файл с одноразовым паролем удаляется.

Если пароль введён неверно несколько раз подряд, учётная запись временно блокируется (см. [Типичные проблемы](TROUBLESHOOTING.md)).

## 2. Обзор интерфейса

Слева — главное меню. Набор пунктов зависит от вашей роли:

- **Главная** — сводка по всем каналам: сколько работает, сколько с ошибкой, сколько выходов онлайн.
- **Каналы** — список каналов и страница каждого канала.
- **Шлюз** — пересылка UDP/multicast-потоков (режимы passthrough, demux, remux, transcode, поддержка FEC). Отдельная от каналов функция; в этой базе знаний не описана. Раздел только для администратора.
- **Плагины** — установка дополнительных модулей (.so). Только для администратора.
- **Мониторинг** — метрики, события, состояние служб.
- **Операции** — стресс-тест и профилирование (оператору и выше).
- **Настройки** — пользователи, LDAP, SMTP, журнал действий, TLS, хранилища, время.
- **База знаний** — справка, в которой вы сейчас находитесь.

Подробнее о ролях — в разделе [Пользователи](USERS_USER.md).

## 3. Создание канала

Создавать каналы может только **администратор**.

1. Откройте **Каналы** → **Создать канал**.
2. Шаг **«Базовые параметры»**: введите имя (латиница, цифры, `_` и `-`; изменить позже нельзя), выберите разрешение, FPS и битрейт. Для первого теста подойдут значения по умолчанию.
3. Шаг **«Назначения выходов»**: оставьте тип **SRT**, адрес `0.0.0.0` и порт `4000`.
4. Нажмите **Создать канал**.

Подробнее: [Создание канала](CREATE_CHANNEL.md).

## 4. Добавление контента

Откройте канал → вкладка **Плейлист**.

- **Добавить файл** — укажите путь к файлу **на сервере** или выберите его кнопкой **Обзор**.
- **Добавить папку** — все медиафайлы из папки добавятся разом.

Файлы не загружаются через браузер: они уже должны лежать на сервере или на подключённой [сетевой шаре](MOUNTS_USER.md).

Подробнее: [Плейлист канала](PLAYLIST_USER.md).

## 5. Запуск

На странице канала нажмите **Запустить**. Через несколько секунд состояние сменится на «работает».

Проверить картинку проще всего прямо в браузере: меню «⋯» → **WebRTC превью**.

Чтобы увидеть поток так, как его видит зритель, откройте в VLC адрес `srt://адрес-сервера:4000` — SRT-выход ждёт подключения зрителя.
