# Плейлист канала

Плейлист — упорядоченный список записей, который канал воспроизводит по кругу. В этой статье — как им управлять вручную.

> Если у канала задан **источник контента** (режим «Кэш» или «Passthrough», см. [Источник контента](CONTENT_SOURCE_USER.md)), плейлист формируется автоматически из содержимого папки. Ручное добавление и удаление при этом отключено, на вкладке виден соответствующий баннер.

## Где открыть

Страница канала → вкладка **Плейлист**. Управлять плейлистом могут оператор и администратор (оператор — только на каналах, где ему выдано право «Управление»).

## Файлы не загружаются через браузер

Плейлист хранит **пути к файлам на сервере**. Перетаскивания файлов из браузера и загрузки через интерфейс нет: файлы должны уже лежать на сервере или на подключённой [сетевой шаре](MOUNTS_USER.md) (она видна на сервере в `/mnt/liveqx/`).

## Добавление записей

Над списком три кнопки:

### Добавить файл

Введите путь к файлу на сервере или выберите его кнопкой **Обзор**. При желании задайте длительность (для фотографий). Нажмите **Добавить**.

Обзор файлов доступен только администратору; оператор вводит путь вручную.

### Добавить папку

Укажите папку на сервере — в плейлист добавятся все медиафайлы из неё сразу. После добавления показывается, сколько файлов добавлено.

### Добавить live-источник

Запись, которая вставляет в эфир внешний поток на заданное время. Подробнее: [Live-источники](LIVE_INPUT_USER.md).

### Поддерживаемые форматы

В диалоге выбора файлов доступны:

- **Фотографии:** PNG, JPG/JPEG, WebP, BMP.
- **Видео:** MP4, MOV, MKV, AVI, TS, M2TS, WebM.

При автоматической синхронизации с папкой действует более узкий список — см. [Источник контента](CONTENT_SOURCE_USER.md).

## Порядок воспроизведения

Записи проигрываются сверху вниз; дойдя до конца, плейлист начинается заново.

Чтобы изменить порядок, используйте стрелки **Вверх** и **Вниз** в строке записи. Перетаскивания мышью нет. Случайного перемешивания тоже нет.

## Редактирование записи

Кнопка **Редактировать** в строке открывает окно, где можно изменить:

- путь к файлу;
- **длительность** (в секундах) — только для фотографий; для видео игнорируется. Пустое значение означает «взять длительность по умолчанию у канала»;
- для live-записи — тип, URL, длительность, прогрев и порог потери сигнала.

## Длительность

- **Фотография** показывается столько секунд, сколько задано в её записи, а если там пусто — столько, сколько указано в настройке канала «Длительность фото по умолчанию» (10 секунд, если не менялось).
- **Видео** играет столько, сколько длится файл. Изменить это нельзя.

## Заглушка

Если плейлист пуст или файл недоступен, канал показывает **заглушку** — статичную картинку. Задаётся на вкладке **Конфигурация** в блоке **Заглушка**: путь к PNG, JPG, WebP или BMP на сервере. Изменение применяется **после перезапуска канала**. Если заглушка не задана, показывается чёрный кадр.

## Удаление и очистка

- Кнопка удаления в строке убирает запись из плейлиста. Сам файл на диске не удаляется.
- Кнопка **Очистить** убирает все записи.

## Если файлы пропали с диска

Если часть файлов из плейлиста перестала существовать, вверху появляется предупреждение «Обнаружены отсутствующие файлы» с кнопкой **Пересканировать плейлист**.

## Журнал воспроизведения

Вкладка **Лог** показывает, что и когда играло: время, статус (`completed`, `skipped`, `removed`, `error`), путь, тип, переход, сколько сыграно и причину ошибки. Есть фильтры по времени, статусу и поиск по тексту.

Журнал работает, только если в **Конфигурации** включена запись воспроизведения (Файл или SQLite); иначе вкладка сообщит, что журнал отключён.

Кнопка **Очистить лог** удаляет записи за выбранный период (старше 7 дней, старше 30 дней, по текущим фильтрам или весь лог) — необратимо.

На вкладке также есть просмотр файла `channel.log` в реальном времени; он доступен только администратору.

## Частые вопросы

**Что будет, если в плейлисте одна фотография?**
Канал будет показывать её бесконечно. Это нормальный режим для информационных экранов.

**Можно ли менять плейлист на работающем канале?**
Да, изменения применяются без остановки.
