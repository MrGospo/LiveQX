# Расписание

Расписание позволяет каналу **автоматически переключаться на другой плейлист** в заданные часы. Например: утром играет один набор роликов, вечером — другой, а по выходным — особый.

Важно: расписание **не запускает и не останавливает** канал. Запуск и остановка выполняются вручную кнопками **Запустить** и **Остановить**. Расписание лишь решает, *что* играет работающий канал.

Открывается на странице канала → вкладка **Расписание**. Изменять расписание могут оператор (при праве «Управление» на канал) и администратор.

## Как это работает

- У канала есть **обычный плейлист** (вкладка «Плейлист»).
- Каждая запись расписания — это **окно времени** и **свой плейлист**. Пока окно активно, канал играет плейлист записи.
- Когда ни одно окно не активно, канал возвращается к обычному плейлисту.
- Если одновременно активны несколько окон, побеждает запись с **большим приоритетом**.

Вкладка показывает блок **Сейчас активно** (какая запись действует), список **ближайших срабатываний** и суточную шкалу.

## Параметры записи

- **ID** — уникальное имя записи.
- **Приоритет** — число от 0 до 1000 (по умолчанию 100). При пересечении окон выигрывает большее значение.
- **Режим повтора:**
  - `loop` — плейлист записи крутится по кругу, пока активно окно;
  - `play_once_then_idle` — плейлист проигрывается один раз, дальше канал ждёт конца окна.
- **Жёсткое переключение** — если включено, в момент начала окна текущий клип прерывается сразу. Если выключено, переключение произойдёт на ближайшем стыке клипов.
- **Действует с / по** — необязательные даты (включительно), вне которых запись не работает. Удобно для сезонных и праздничных записей.
- **Плейлист** — пути к клипам на сервере, которые играют в окне.
- **Переход** — тип, режим, длительность и кривая перехода при переключении. См. [Переходы](TRANSITIONS_USER.md).
- **Повторение** — когда срабатывает окно (см. ниже).

## Виды повторения

- **Один раз (once)** — от точной даты и времени начала до точной даты и времени конца. Время указывается в **UTC**. Начало включительно, конец исключительно.
- **Ежедневно (daily)** — каждый день с **времени начала** до **времени конца**.
- **По дням недели (weekly)** — то же окно, но только в выбранные дни недели.
- **По дням месяца (monthly)** — то же окно в выбранные числа месяца (1–31). Если такого числа в месяце нет (например, 31 февраля), запись в этот месяц просто пропускается.

Окно, которое **переходит через полночь** (например, 22:00–02:00), сейчас **не поддерживается**: время конца должно быть позже времени начала. Для ночного эфира создайте две записи: до 23:59 и с 00:00.

## Часовой пояс

Время начала и конца для ежедневных, недельных и месячных записей считается в **часовом поясе канала**. По умолчанию канал наследует часовой пояс сервера; его можно задать отдельно на вкладке **Конфигурация** → **Часовой пояс** (изменение применяется при следующем запуске канала). Подробнее — в [Время сервера](TIME_USER.md).

Записи «один раз» всегда задаются в UTC.

## Несколько записей

Записей может быть сколько угодно. Например:

- 06:00–10:00 каждый день — утренний плейлист (приоритет 100);
- 18:00–23:00 по будням — вечерний плейлист (приоритет 100);
- 12:00–13:00 по пятницам — специальный плейлист (приоритет 200, перекрывает остальные).

## Если расписание срабатывает не вовремя

1. Проверьте часовой пояс сервера и канала — см. [Время сервера](TIME_USER.md).
2. Убедитесь, что для записей «один раз» время указано в UTC.
3. Проверьте даты «Действует с / по» и приоритеты пересекающихся записей.
4. Откройте блок **Ближайшие срабатывания** и сверьте время со своими ожиданиями.

## Праздничные дни

Отдельной поддержки праздников нет. Для особого дня добавьте запись «один раз» или запись с датами «Действует с / по» и более высоким приоритетом.
